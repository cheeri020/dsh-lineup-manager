# dsh-lineup-manager

**DeepSeek Harness के मॉडल चयनकर्ता में कौन-सी मॉडल लाइनें दिखें, यह चुनें — प्रदाता के अनुसार समूहित, और हर प्लेटफ़ॉर्म से लाइव रीफ़्रेश।**

[English](README.md) · [简体中文](README-zh.md) · [Español](README-es.md) · [Português](README-pt.md) · [हिन्दी](README-hi.md)

> यह अनुवाद केवल संदर्भ के लिए है। पूर्ण और अद्यतन विवरण English में है।

## Compatibility

| सतह | स्थिति |
|---|---|
| Harness | DeepSeek Harness `0.2.1-rc.2` |
| Node | `^22.19.0 || >=24.0.0` |
| प्लेटफ़ॉर्म | सभी (सादा ESM; कोई नेटिव कोड नहीं, कोई बिल्ड टूलचेन नहीं) |

## The problem

DSH मॉडल चयनकर्ता को प्रदाता के अनुसार समूहित करता है, लेकिन कितनी प्रविष्टियाँ दिखेंगी यह आपकी कॉन्फ़िग पर निर्भर है: जो प्रदाता `models:` सूची घोषित करता है उसमें केवल वही लाइनें दिखती हैं; बिना सूची वाला प्रदाता एडाप्टर की पूरी कैटलॉग दिखाता है, जिसमें सैकड़ों प्रविष्टियाँ हो सकती हैं। केवल निःशुल्क लाइनें रखने के लिए YAML हाथ से संपादित करना पड़ता था।

## Features

- प्रत्येक घोषित लाइन के लिए प्रदाता-वार चेकबॉक्स
- प्रति प्रदाता सामूहिक क्रियाएँ: **सभी** / **कोई नहीं** / **केवल free**
- **रीफ़्रेश** — प्लेटफ़ॉर्म की वर्तमान सूची लाता है और **नई** तथा **हटी हुई** लाइनें चिह्नित करता है
- नई लाइनें तुरंत चुनी जा सकती हैं, कॉन्फ़िग में मौजूद होने से पहले भी

## Install

```sh
pnpm pack
dsh plugin add ./dsh-lineup-manager-0.2.0.tgz
```

इसके बाद DSH पुनः आरंभ करें।

## Usage

1. **सेटिंग्स → "Lineups" बटन** खोलें
2. पैनल प्रत्येक प्रदाता और प्रत्येक लाइन के लिए चेकबॉक्स दिखाता है
3. **सभी** / **कोई नहीं** / **केवल free** का उपयोग करें, फिर उस समूह में **सेव** दबाएँ
4. मॉडल सूची में बदलाव दिखने के लिए **DSH पुनः आरंभ करें**

## Safety

प्रत्येक लेखन से पहले टाइमस्टैम्प वाला बैकअप बनता है, संरचनात्मक जाँच होती है, और पढ़कर सत्यापन किया जाता है जो मेल न खाने पर वापस लौटा देता है। केवल लक्षित प्रदाता का `models:` ब्लॉक बदला जाता है; बाकी फ़ाइल अछूती रहती है।

## How refresh works (and the traps)

- **रीफ़्रेश कभी लिखता नहीं**: केवल चिह्नित करता है; सेव दबाने तक कुछ नहीं बदलता
- **pi-ai की अंतर्निहित कैटलॉग से बचा जाता है**: उसे पूछने पर आपके DSH संस्करण पर जमी पुरानी सूची मिलती, यानी बासी डेटा
- **401 `api_key_expired`** उस प्रदाता की विफलता के रूप में दिखता है, बाकी पर असर नहीं
